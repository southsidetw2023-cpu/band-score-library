# 合奏庫｜樂團樂譜管理原型

本機可操作的第一版原型，使用 PPC 敬拜團 Google 試算表的 207 筆資料建立樂譜庫介面。

公開預覽：<https://southsidetw2023-cpu.github.io/band-score-library/>

> 目前是公開介面原型，尚未啟用 Google 登入、成員核准與私有檔案權限。

## 已完成

- 依歌名、出處、語言、年份搜尋
- 讚美／敬拜分類與歌譜狀態篩選
- 歌曲詳細資料與原始資源連結
- 本週排練歌單（保存在瀏覽器本機）
- 管理者匯入、權限與批次上傳流程預覽
- 手機、平板與桌面響應式介面

## 尚未啟用

- Google 登入與管理者核准
- 私有檔案儲存與 Google Drive 搬移
- 團隊即時同步、共用／個人筆記
- PDF 閱讀器與離線快取

## 本機執行

```bash
npm install
npm run import:data
npm run dev
```

正式串接外部服務前，先確認資料授權、檔案分享範圍與備份策略。
